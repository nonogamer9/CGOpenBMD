# CGOpenBMD

This is a full Open Source ByteMatched Decompilation of Chicken Gun (Version 1.2.6) made by nonogamer9 using AssetRipper. This was made to be as accurate as possible.
Instead of most Chicken Gun decomps which includes dll files, this one has no dll files, it has all of the dll files obfuscated so you can easily modify the codes.
For example PUN or ProBuilder.

Unity Version matches exactly what ChaloApps used back in May 2019 (Unity 2018.2.17f1 to be exact.)

# How To Open It

* Download the Repo
* Extract the Repo using 7-ZIP or WinRAR
* Open The Repo using Unity 2018.2.17f1 (Other Unity 2018+ Versions would be fine)
* Profit
